🏎️ CORECAMÓVIL

Vehículo Robótico Radiocontrolado por Wi-Fi de Baja Latencia (ESP-NOW)

Sistema de Seguridad Fail-Safe Activo

📌 Descripción del Proyecto

El Corecamóvil es un vehículo todoterreno operado mediante un mando a distancia inalámbrico desarrollado sobre la arquitectura de microcontroladores ESP32. Utiliza el protocolo de comunicación peer-to-peer ESP-NOW de Espressif, garantizando una respuesta ultrarrápida sin necesidad de un enrutador o red Wi-Fi externa.

⚙️ Arquitectura de Hardware

  • Control Transmisor (Mando): ESP32 + Joystick analógico de 2 ejes (X, Y).
  • Receptor (Carro): ESP32 en modo estación con filtrado de paquetes.
  • Etapa de Potencia: Configuración de Doble Puente H L298N independiente para balanceo de carga de corriente.
  • Motores: 4 motores DC accionado por batería de alta potencia de 20V.
  • Indicador Visual: LED integrado GPIO 2 para diagnóstico de estado de red.

🛡️ Mecanismo de Seguridad (Fail-Safe)

El vehículo cuenta con un algoritmo de protección ante pérdidas de señal:

// Timeout de seguridad en milisegundos
if (conectado && (millis() - ultimaRecepcion > 1000)) {
  detenerMotores(); // Detención automática inmediata
  digitalWrite(LED_CONEXION, LOW);
}

Si la señal de comunicación con el mando se interrumpe por más de 1 segundo, el receptor apaga automáticamente la tracción para prevenir colisiones.

📶 Protocolo de Comunicación ESP-NOW

A diferencia de los protocolos tradicionalmente usados como Bluetooth o Wi-Fi HTTP, ESP-NOW transmite tramas de datos crudas a nivel MAC, reduciendo la latencia de respuesta del vehículo a menos de 5 milisegundos.
